# 秋招简历大结果 Skill

帮你改简历，秋招不用愁。

把现有简历、项目经历、JD 或截图丢进来，它会帮你提炼重点、优化表达、匹配岗位，并生成一份可以直接投递的简历。

## 能识别什么

PDF、Word、图片、截图、纯文本都可以。你也可以直接用大白话描述经历，比如：

```text
我做过一个商家自动接单项目，漏单率从 8% 降到 3%，想投产品岗，帮我改成简历表达。
```

## 怎么改

原始表达：

```text
• 负责商家接单功能的需求分析与产品设计
• 与算法、开发团队配合，推动策略上线
• 上线后提升了商家履约体验
```

优化后：

```text
• 分析高峰期漏单原因，发现人工接单动作在忙时容易被挤出商家操作优先级，
  将方案从「提醒商家点击」调整为「系统辅助判断是否接单」
• 设计「备货能力 + 骑手运力」双维度判定机制，降低单一信号带来的订单积压
  或后厨产能超载风险
• 推动策略上线后，漏单率由 8% 降至 3%，且出餐超时率保持稳定
```

它不会帮你编经历，只会把你已有的内容讲清楚、讲得更像岗位需要的表达。

## 会给你什么

- 一份按岗位润色后的简历内容：会结合产品、运营、金融等知识库，识别你的真实经历和目标岗位需求，再决定哪些重点该前置、哪些表达该强化
- 多套可切换的简历模板：标准单栏、左右双栏、项目型、投行咨询风、中英标题等，适配不同岗位和投递场景
- 一个可直接打开的 HTML 简历：不用再手动排版，内容、模板、公司 logo、页面长度都会一起处理
- 可以在 HTML 上继续编辑、调整排版、导出 PDF：生成后还能自己微调文字和样式，改完就能投

一次改好，后面投不同岗位只需要微调重点，不用每次从头重写。

## 用之前

需要 Python 3.8+ 和 fonttools：

```bash
pip install fonttools
```

首次生成简历时会自动下载中文字体（约 40MB，只下一次，之后离线可用）。

生成的 HTML **请用系统浏览器打开**（Chrome / Safari / Edge）。IDE 或 AI 工具右侧的预览面板是受限环境，可能不执行 JS，会导致工具栏和导出 PDF 失效。
