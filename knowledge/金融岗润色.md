# 实习/工作经验/项目经历（金融岗）

解读用户的金融相关经验

## 结构

标题写清：机构名称、部门（投行部/研究部/资管部…）、职位、时间段。经历里的**项目/研究覆盖**尤其重要——买方卖方都是靠项目/覆盖标的说话。

以项目/研究单元为主线填充。每段下用 list 写清这几类信息：

- 交易/研究/项目的背景（行业、标的、规模）
- 用户在其中的具体职责（建模、尽调、路演、报告撰写、路演材料…）
- 产出与影响（成交与否、报告被引用、内部/客户认可）

以上是**要覆盖的信息维度**，不是固定的 bullet 标签。是否加前缀小标签、用什么措辞，按项目实际内容判断，不要每个项目都套同一组词。

## 内容优化表述

金融岗核心看**Hard skills 是否扎实 + 项目/研究是否真实可查**。

重点关注点：

1. **专业深度**：估值模型（DCF/LBO/Comps/Precedents）、财务分析、行业研究方法要具体到"用什么方法做了什么"。
2. **项目/覆盖**：具体标的、行业、交易规模——**不能只说"参与 IPO 项目"**，要说"某消费类 IPO，规模 XX 亿"（合规范围内）。
3. **数据与模型**：用了哪些数据源（Wind/Bloomberg/Capital IQ）、建了什么模型、假设是什么。
4. **结果**：报告是否被采纳、模型是否用于最终决策、项目是否成交——若涉密，用"参与产出"或"支持"这类措辞。
5. **合规意识**：主动区分公开信息 vs 内部信息，避免暴露敏感数据。

## 结合 JD 的定点润色

核心：经历是素材，JD 是镜头，润色是选镜头角度。不改写事实，不把 JD 的词硬塞进简历，而是把经历里与 JD 匹配的侧面加重、置前、强化措辞。

### JD 信号词 → 强调角度

| 细分方向 | JD 信号词 | 应强调的侧面 |
|---|---|---|
| 投行 IBD | IPO、并购、再融资、尽调、路演、招股书、估值 | 参与项目类型、可比公司/交易分析、财务建模、尽调文档产出 |
| 买方（PE/VC/公募/私募）| 尽调、投资决策、组合管理、募投管退、行业研究 | 立项/投决报告贡献、行业判断、投后跟踪、组合调整逻辑 |
| 卖方研究 | 覆盖、深度报告、财务预测、评级、路演 | 覆盖标的与深度、预测模型精度、被引/路演反馈、观点独立性 |
| 风险管理 | 信用风险、市场风险、压力测试、VaR、Basel、合规 | 风险模型搭建、指标体系、压力情景设计、监管对接 |
| 量化 | 因子、策略、回测、Sharpe、IR、机器学习、Python | 因子构建、回测框架、样本内外表现、策略容量 |
| 财务/审计 | 三大报表、合并报表、税务、IFRS/GAAP、审计程序 | 报表编制经验、异常识别、审计程序执行、跨系统对账 |
| 通用（所有方向） | 团队协作、跨部门沟通、抗压、时间管理 | 项目并行、Deadline 交付、跨团队协调 |

### 边界规则

1. 只能调角度 / 权重 / 措辞，不能新增不存在的事实（呼应「证据规则」）
2. 涉密项目名称、金额、内部数据一律匿名化（"某消费类 IPO"、"某中型互联网并购"）
3. 与 JD 错开的侧面，跳过不强套；只强化能对的，绝不硬凑
4. 未通过 CFA/CPA/FRM 等考试不得声称"持有"，可写"CFA Level II Passed / 备考中"

## 证据规则

将团队产出归属于团队。仅在用户的描述支持时，才使用 "主导（led）"、"负责（owned）"、"支持（supported）"或"贡献（contributed）"。**投行/买方项目基本都是团队作战，慎用"主导"。**

不得编造：交易规模、模型精度、报告数量、评级准确率、回测收益。不掌握精确数据时用量级或区间。

区分**已成交项目** vs 未成交/终止项目——未成交的写"参与"，不写"完成"。

**合规红线**：涉及在职/曾任雇主的内部数据、未公开的项目细节、客户信息，一律不写入简历，或做严格脱敏。这不仅是简历规范，更是执业底线。

考试证书要写实：Passed 就是 Passed，Registered 就是 Registered，不能等同于 Certified。

## 好的表述案例

**中金公司 · 投资银行部 · 分析师实习生 · 2024.06 - 2024.09**

**项目：某消费类 A 股 IPO 申报**

- 参与项目组尽调准备与招股书撰写，负责财务分析章节初稿与关键风险识别
- 独立完成可比公司估值模型（10 家 A/H 股同行），基于 P/E、EV/EBITDA 双路径给出估值区间
- 支持路演材料制作，配合分析师完成 3 场机构预沟通材料整理

**项目：某中型医疗器械并购交易（未成交）**

- 参与买方尽调与财务建模，产出合并报表 pro-forma 与协同效应测算
- 项目最终因估值分歧未成交，但相关行业分析框架被复用至后续 2 个类似标的评估
- 从中总结中型医疗器械并购的常见 deal-breaker，写入部门内部案例库
